## Native implementation references

- Shell item context menu is obtained through [IShellItem.BindToHandler](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ishellitem-bindtohandler) / BHID_SFUIObject. [QueryContextMenu](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-icontextmenu-querycontextmenu) populates a classic native menu. CMF_CANRENAME is intentionally absent because this host has no Explorer in-place rename surface.
- The temporary same-thread [SetWindowSubclass](https://learn.microsoft.com/en-us/windows/win32/api/commctrl/nf-commctrl-setwindowsubclass) callback forwards extension menu messages and is removed before command invocation and in failure cleanup.
- Recycling uses [IFileOperation flags](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ifileoperation-setoperationflags), pre-delete veto and the [PostDeleteItem recycled-item result](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ifileoperationprogresssink-postdeleteitem). No permanent-delete fallback is implemented by the app. Native unavailable-bin behavior remains a manual acceptance case.


- Additional headless mouse input test uses Fluent templates and real right/left input events: right-click targets the expected file, and clicking the red cross never opens it. No native Shell callback is executed. Log: TestResults/history-input.log.

# ShareVibeX 0.11.0 — история в настройках

Пользователь сообщил, что проверка 0.10.2 прошла успешно. Ниже — проверка новых действий истории. Для неё используйте ненужные тестовые захваты. Нативные действия Windows агентом не запускались.

1. Откройте Settings → History либо «История захватов» в трее. Открывается то же окно настроек, выбран раздел истории. Проверьте оба языка. Дерево месяцев, сортировка новых записей сверху и миниатюры сохраняются.
2. Нажмите превью или имя снимка/видео: файл открывается приложением по умолчанию. Кнопок Open и Folder нет. Клавиатурой можно перейти к записи и открыть её Enter.
3. Нажмите ПКМ по записи. Открывается системное Shell-меню выбранного файла (классическое меню Windows, а не копия меню приложения). Проверьте «Открыть», «Копировать», «Свойства» и отмену меню. Доступные команды зависят от Windows, типа файла и расширений; встроенное Explorer-переименование не заявляется этим хостом меню.
4. Нажмите красный ×. Файл должен исчезнуть из истории и оказаться в Корзине. Проверьте восстановление через Корзину и обновление истории. Если Корзина недоступна, операция должна отказаться от удаления; автоматического безвозвратного удаления нет.
5. Удалите ненужный файл через системное меню и проверьте обновление списка. При отложенной операции Windows используйте Refresh. Ошибка доступа/отмена красного × сохраняет запись и не открывает файл.
6. Несколько раз перейдите из истории в другие разделы и обратно, обновите список и закройте настройки во время загрузки миниатюр. Не должно быть зависания или появления старых строк.
7. Во время записи/видеопредпросмотра откройте историю через трей. История доступна; остальные разделы и сохранение настроек заблокированы до завершения сеанса. Восстановление прерванных записей по-прежнему требует закрытого текущего сеанса.

Изменения файлов в истории применяются сразу и не требуют Save settings. Перенос файла в Корзину может нарушить ссылки на этот файл в других приложениях.

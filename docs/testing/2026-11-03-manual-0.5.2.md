# ShareVibeX 0.5.2 — editor UI checks

Internal tests only; native acceptance belongs to the user. Exit the previous copy and extract the entire ZIP. General > Button size saves 24–64 logical pixels for capture/recording/editor actions; check persistence and DPI.

Video toolbar width is independent of region width (monitor-clamped). Previous/Next frame use the prior Set A/B icons; Set A/B are square brackets. Hold Ctrl for Delete A–B instead of Keep A–B. Check Ctrl pressed before moving between video and toolbar, and released afterward.

Current-frame and A/B times sit between video and controls. Hover track is transparent with rounded ends; A/B is the colored interval. Drag its endpoints; no visible vertical A/B sticks remain. Ctrl+Z cancels an active export/edit; there is no Cancel action button.

The last toolbar button is Discard video (trash). It immediately stops resources, closes preview and deletes owned recording files without a Save prompt. Previously copied cache files and saved destinations must survive. App exit still retains its separate unsaved-decision flow. Follow the 0.5.1 checklist for capture/audio/clipboard regressions.

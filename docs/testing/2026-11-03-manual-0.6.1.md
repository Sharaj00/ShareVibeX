# ShareVibeX 0.6.1 manual verification

1. General → Startup: both startup preferences are off by default. Merely open and cancel Settings: Windows Startup apps must remain unchanged.
2. Enable Run ShareVibeX when Windows starts and Save. Verify Windows Startup apps/Run lists this executable (including a folder path with spaces).
3. Disable and Save: only ShareVibeX's own entry should disappear; other startup applications remain untouched.
4. Move a portable copy after enabling autostart. Open Settings in the new copy and explicitly re-enable/save: registration should point to the new executable. Startup itself must not repair entries silently.
5. Enable Open settings on startup, Save, Exit and restart: Settings should appear. Disable it and restart: tray-only startup should return.
6. Verify screenshots, video export and capture history remain usable.

Internal tests use injected in-memory startup registration; the agent did not modify real autostart or launch native GUI/device/clipboard checks. Tray action configuration and complete English/Russian localization belong to subsequent Stage 3 batches.

# ShareVibeX 0.11.2 — доступность микрофона

1. Без подключённого/активного микрофона выберите область → Video. Кнопка микрофона должна отключиться и показывать подсказку «Не найдено доступное устройство записи». Проверка состояния асинхронная.
2. Запишите видео без микрофона: настройки не должны открываться автоматически. При необходимости отдельно отключите системный звук для полностью беззвучной записи.
3. Подключите микрофон, оставаясь в режиме Video: состояние перепроверяется примерно раз в две секунды. Кнопка снова доступна; микрофон сам не включается после переподключения.
4. Отключите выбранный микрофон перед Record или во время записи и попробуйте включить его. Кнопка/сообщение должны отражать отсутствие устройства; ошибка не открывает настройки принудительно. Потеря уже используемого устройства может остановить запись с сообщением на панели.
5. Проверьте оба языка. Если в Settings выбран конкретный отключённый микрофон, выберите доступное устройство либо системное устройство по умолчанию. Проверяется доступность выбранного источника.

Реальные аудиоустройства, горячее подключение, захват и интерфейс Windows агентом не запускались. Внутренние тесты используют подменённые списки устройств и headless-панели.

# ShareVibeX 0.3.2 — user checks

No real application window, capture/compositor harness, clipboard, audio device or FFmpeg was run by the agent. Internal tests used synthetic images and headless controls. Actual recording is the next stage; the roadmap is planning, not implemented functionality.

## Selection

1. Exit the older copy through the tray, extract the whole new ZIP and start ShareVibeX.App.exe.
2. Invoke capture over moving content. Initially there should be no instruction banner, frozen image or screen dimming.
3. Drag a region: show its rectangle and a resolution-only hint near the cursor, with no mode toolbar or drag handles during the gesture. Move/resize an existing region and check the same hint behavior.
4. Release: the hint disappears; exactly three compact vector buttons appear — screenshot camera, video camera, cancel. Hover for English tooltips; verify keyboard focus. Handles can appear for subsequent resize.
5. Press Enter or Ctrl+C before choosing a mode: copy a fresh unedited crop and close the overlay. This still works if the camera button has keyboard focus.
6. Click the screenshot icon: freeze at that action and show the existing editor in place. Annotate/copy/save as before. Click cancel or press Escape/right-click: close the session without an export.
7. Select Video and Back: keep the region live and return to the three icons. Recording buttons remain disabled in this correction build.
8. If available, test mixed DPI, negative coordinates, dragging across monitors and selection near screen edges. The resolution hint belongs near the cursor on its current monitor, shows full-region physical dimensions and must not appear in output.

## Settings location

General must have no Portable data / Settings folder row. Settings always use data/settings.json beside this executable. Save/reopen preferences and confirm the file location. Old --data-dir overrides are unsupported; existing external files are not moved automatically.

For a read-only portable folder, recovery should offer Retry, Back up and reset settings, and Exit; it should explain moving the portable application to a writable location, without choosing a different data folder. Check this only in a disposable copy if desired; preserve your settings.

# ShareVibeX 0.6.0 manual verification

1. General: enable capture history. Verify the default C:\Pictures\Screenshots folder or choose another writable root. Save settings and restart to check persistence.
2. Capture an application and use Copy. The history archive must match the copied image including annotations, use configured image quality/format, and live in the capture-date yyyy-MM folder.
3. Save a screenshot to another folder. Check its suggested application_yyyyMMdd_HHmmss name and the independent history archive.
4. Copy/save two results in the same second: existing history files must survive, with suffixes for collisions.
5. Record, trim A–B, Copy/Save. The archived video must contain the edited result, not the original. Discard a fresh unexported video: no new history file should appear.
6. Tray Capture history: open image/video and folder. Recover interrupted recordings should still reach the previous recovery tools.
7. Disable history: Copy/Save must continue working without adding files or deleting earlier history.
8. Use an unwritable history folder: a useful error should appear and the already copied/saved result must survive.
9. Settings navigation contains General, Image and Video only.

Native capture, clipboard receivers, audio and visual acceptance are performed by the user; automated tests do not substitute for these checks.

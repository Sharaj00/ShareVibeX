# ShareVibeX 0.7.1 manual verification

1. Open Settings, choose Русский, press Save settings. The footer should show progress while saving; the window should close on success.
2. Reopen Settings: General and section headings should be Russian. Restart the application and verify the language persists.
3. Switch to English, Save and reopen; check English returns.
4. Keep the shortcut and autostart unchanged while switching language: unrelated shortcut conflicts or startup entries must not block saving.
5. Changing the shortcut itself still validates availability; explicitly changing autostart still uses its registration transaction.
6. On a save error the footer must display the error and editing becomes available again. Existing saved settings should remain intact.

This build removes confirmed unrelated-operation blockers; the user's exact native no-response symptom has not been reproduced in internal tests. Tests now simulate mouse press/release, portable JSON persistence and reopening the translated Settings window, with unavailable unchanged shortcut/startup callbacks. Native acceptance remains user-owned.

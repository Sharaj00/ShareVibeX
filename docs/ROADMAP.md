# ShareVibeX roadmap

The Windows workflow is implemented and accepted for version 0.18.0. The app supports live region screenshots, annotations, structured FFmpeg recording, preview and trimming, optional history, and portable settings.

True exclusive fullscreen uses a direct monitor screenshot. The interactive selection and editing workflow applies to windowed and borderless applications.

The next development stage is Linux x64, starting with Wayland through XDG Desktop Portal and PipeWire. See the [Linux implementation plan](../LINUX.md) and the [portability assessment](linux-portability-assessment.md).

See the [changelog](../CHANGELOG.md) for delivered changes and the [Windows verification guide](testing/WGC-video-manual.md) for regression checks.
